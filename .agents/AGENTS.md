# General Rules & Guidelines

- **Code Formatting & Quality**: 
  - After making any code modifications, you MUST run `prettier` to format the code.
  - You MUST run `lint` (e.g., `yarn lint` or `npm run lint`) to ensure there are no linting errors.
  - You MUST run `tsc --noEmit` to check for TypeScript errors.
- **Documentation**: 
  - Always update the relevant documentation (e.g., README, inline comments, or docstrings) to reflect the changes made to the codebase.
